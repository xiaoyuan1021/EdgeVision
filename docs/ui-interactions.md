# 界面事件与配置边界

所有 Designer 页面禁用 `uic` 自动连接（`--no-autoconnection`）。控件保留原 objectName；槽使用 `onApplyClicked` 一类语义名称，在所属 Widget 的构造或 `setupConnections()` 中以函数指针显式连接。不要再添加 `on_控件名_信号名` 或字符串版 `SIGNAL/SLOT`。

事件分成三条路径：

1. `loadFromConfig` / `set…Config`：只回填控件及本地草稿。阻断控件信号，不修改 Pipeline、不保存检测项、不触发执行。
2. 用户编辑：更新该页面拥有的配置字段。需要实时预览的滑块只通过一条值变化路径提交；Slider/SpinBox 双向绑定后只监听 Slider 执行业务处理。
3. 应用/识别：提交配置一次，再通知执行一次。`ISignalConnectable::connectSignals` 在每个实例生命周期内只接线一次，重复初始化不会累积回调。

`DetectionUiController` 在选中检测项时先建立完整配置，再回填各页；`RoiDetectionConfigController` 按 ROI ID + 检测项 ID 写回，避免修改同类型的其他检测项。树和图片列表回填用 `QSignalBlocker`，用户鼠标和键盘选择采用相同的当前项变化事件。

增强撤销历史在加载另一份配置时重置；“重置”只影响增强字段。颜色过滤保存全部 Gray/RGB/HSV 参数。配置导出从当前 Pipeline 快照开始，未创建页面的参数也能保留。检测项切换前保存旧项完整快照；导出文件与保存方案在序列化 ROI 之前提交当前编辑。直线参数通过一个提交信号写回检测项，回填和显示状态更新不发出编辑信号。

## 回归验证

在仓库根目录运行 `test-ui-msvc.cmd`。该目标链接与桌面程序相同的 `EdgeVisionRuntime`，在 Qt offscreen 平台实例化生产 Widget、操作真实控件并核验信号次数。覆盖配置回填、应用/重置/撤销、双向控件绑定、重复接线、图片和 ROI 选择、多个同类检测项、异步结果归属、批量暂停/恢复/停止。

摄像头、真实视频流、CUDA 和模型准确率仍需在对应硬件与数据上验收；offscreen 测试不替代视觉布局检查。

跨页面流程由 `application/DetectionWorkspace` 负责，图片与预览由 `InspectionSession` 负责。图片删除后根据剩余图片重新恢复页面，不无条件隐藏。`test-ui-msvc.cmd` 同时运行生产页面交互与应用流程测试，职责与关闭顺序见 [架构边界](architecture.md)。

## 注释与简化约定

注释说明当前约束、数据归属、时序和非显然的原因。修复历史放在 Git 和重构记录中，不在生产代码累积 `[FIX]`、`[NOTE]`、旧实现或注释掉的执行语句。接口注释必须与当前实现一致。

检测项选择先组装完整配置，再统一保存和回填；同一控件不叠加专用 setter 与通用回填。OCR 判定字段、未实现通用配置接口的页面保留显式处理。按钮能直接连接所属控制器时，不添加仅转发调用的窗口槽。删除保护代码前应确认其约束已由其他路径覆盖；信号屏蔽、单任务在途状态、任务快照和关闭等待都有回归用例保护。

## 画布与布局

`ImageView` 的视口逻辑在 `image_view_viewport.cpp`，绘制交互在 `image_view.cpp`。缩放比例直接读取视图变换，不另外保存副本。`ImageViewControls` 只绑定显示操作，通过 `viewChanged` 更新尺寸、比例和按钮状态，不参与检测配置或执行。

绘制的状态、几何及草稿管理在 `image_view_drawing.cpp`；鼠标/键盘事件分派留在 `image_view.cpp`。`DrawingMode` 互斥地选择 ROI、多边形、区域矩形或参考线。画布不存在图像或被视频锁定时不开始绘制。确认数据先复制，结束草稿后再发信号，接收方可以同步切图或启动下一工具。

Esc/工具条“取消”丢弃当前草稿；Enter/右键确认 ROI、多边形和参考线，区域矩形仍在松开左键时确认。多边形支持 Backspace 撤回，至少三个非共线点才能确认。确认后的多边形保留供创建模板读取；取消新的参考线草稿不删除已确认的线。图像/ROI 身份或尺寸改变会清理覆盖层，同尺寸结果刷新保留正在编辑的草稿。绘制提示显示在画布工具条，大小不随图像缩放。

开始绘制须位于图像内，拖拽终点可裁到边界；ROI 缩放保留对边、最小 3×3 像素，整体移动保留尺寸。像素读数使用未裁剪的坐标，空白画布不冒充边缘像素。参考线起点用可选值表达，合法的 `(0,0)` 不代表“未设置”。

- `setImage` 用于切换图像/ROI，进入适应模式；`setImageKeepZoom` 用于同尺寸预览和结果更新，保留手动缩放与滚动位置。图像尺寸变化时自动重新适配。
- 适应模式随窗口/分隔条调整；手动模式保持比例。手动缩放限制在 1%–6400%，横向/零增量滚轮不改变比例。100% 表示一个图像像素对应一个视图逻辑像素。
- 无图像或视频锁定时禁用工具条操作。画布空态提示与图像绘制分离，不创建可导出的伪图像。
- 资源与参数面板采用滚动容器，保留原有控件身份；中间画布优先获得新增宽度。密集参数页面通过滚动访问，不再强制撑宽主窗口。

运行 UI 测试前可设置 `EDGEVISION_UI_CAPTURE_DIR`，生成空态、1280×720 与 1920×1080 的真实 QWidget 截图；图像为测试内生成的示例，不访问用户文件。
